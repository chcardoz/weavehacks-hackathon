Redis is not a side note in keepalive — it does five distinct jobs. Run it from the
`redis:8` image (the query engine is in core now; `redis-stack` is legacy).

## The five uses

<CardGroup cols={1}>
  <Card title="1. Streams + consumer groups" icon="stream">
    Failure events flow through Redis **Streams with consumer groups** (not pub/sub), so
    events are durable and acknowledged — nothing is lost if a consumer restarts mid-incident.
    Stream `keepalive:events`, group `keepalive`.
  </Card>
  <Card title="2. ZSET deadline polling" icon="clock">
    Escalation timeouts live in a sorted set (`keepalive:deadlines`) scored by due-time.
    keepalive polls for due deadlines; when one fires with no human reply, authority
    transfers. (Keyspace `Ex` notifications are best-effort demo flair only.)
  </Card>
  <Card title="3. Agent Memory Server" icon="brain">
    The headline integration. Working memory holds per-incident context; long-term memory
    gives cross-run incident recall with semantic search and dedup. This powers the
    "I've seen this NaN pattern before" moment in diagnosis. Runs as one Docker container
    plus `pip install agent-memory-client`.
  </Card>
  <Card title="4. RedisVL SemanticRouter" icon="route">
    Classifies a raw failure signal into an incident category
    (divergence / thermal / dataloader / oom) via embedding KNN — **no LLM call** needed
    for routing.
  </Card>
  <Card title="5. RedisVL SemanticCache" icon="database">
    Caches near-identical probe diagnostic LLM calls, so repeated/similar diagnoses skip
    the model round-trip.
  </Card>
</CardGroup>

## What each buys you

- **Streams** → durability and replay; an interrupted incident resumes cleanly.
- **ZSET deadlines** → the authority-transfer state machine, with no reliance on
  unreliable expiry events.
- **Agent Memory** → diagnoses get smarter over time and reference real past incidents.
- **SemanticRouter** → fast, free categorization that shapes which fixes to try.
- **SemanticCache** → fewer LLM calls, lower cost, faster probe-side reasoning.

<Warning>
Redis vectors must stay **bytes** (`np.float32(...).tobytes()`). Do **not** set
`decode_responses=True` on a client that handles vectors — it corrupts them. KNN queries
need `.dialect(2)`, and a dimension mismatch fails silently.
</Warning>

Skipped deliberately: LangCache (managed preview) and Vector Sets (redundant here).

## Running it locally

See `infra/redis.md` and `infra/docker-compose.yml` for a local stack: `redis:8` plus the
Agent Memory Server container, with `REDIS_URL` wired through and `OPENAI_API_KEY` provided
for embeddings.
