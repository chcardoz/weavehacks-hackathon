The demo is strictly **3 minutes**. It uses a tiny training run (nanoGPT / CIFAR) with a
fault injector and a short timeout so the whole incident plays out live.

## Setup before you walk on stage

- Tiny model, fast steps — the run should reach the injected fault in seconds.
- Real card on the Twilio account (trial accounts only text verified numbers and stamp a
  prefix). See [escalation](/escalation#twilio-caveats-self-hosters).
- Your phone in hand, ringer on, number verified with the relay.
- W&B dashboard open to the parent run's project (the probe race is the visual).
- The relay, Redis, and Agent Memory Server all up. See `infra/`.

## The fault injector

The demo training script accepts an injector flag that forces a deterministic failure at a
known step:

```bash
keepalive run -- python train.py --inject nan@step400
```

This makes the loss go NaN at step 400, so the watchdog fires on cue.

## Demo timing

Drop the escalation timeout to ~20s so authority transfers while you're still on stage:

```bash
export KEEPALIVE_TIMEOUT=20
```

## The on-stage beats

<Steps>
  <Step title="Run starts, fault injects">
    Kick off training. At step 400 the loss goes NaN and the watchdog catches it instantly.
  </Step>
  <Step title="SMS arrives live on stage">
    Your phone buzzes: a plain-English diagnosis, a voice-note link, and the reply menu.
    Read it out. Optionally mention "I've seen this NaN pattern before" — memory recall.
  </Step>
  <Step title="You ignore it">
    Don't reply. Let the 20s deadline expire. Authority transfers — keepalive stops waiting.
  </Step>
  <Step title="Probe race on the W&B dashboard">
    Cursor agents push `cursor/probe-*` branches; keepalive races them from the last
    checkpoint on W&B Sandboxes. Switch to the W&B dashboard: multiple grouped probe runs
    appear, loss curves diverging. The winner is the lowest curve.
  </Step>
  <Step title="Recovery SMS with the Weave trace">
    keepalive promotes the winner, opens a PR, and texts you a recap with a link to the
    full Weave trace. Open the trace: one incident, one tree, every agent decision.
  </Step>
</Steps>

<Note>
The Weave link is a hard hackathon requirement and the strongest part of the close — make
sure the recap SMS lands and the trace opens cleanly.
</Note>
